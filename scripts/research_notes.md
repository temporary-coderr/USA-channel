# WISE LAB — Research notes and source ledger

This file is paired with scripts/script.txt. Keep it updated in the same commit whenever the script changes.

For every factual research claim in the narration, record:
- Claim as stated in the script (short paraphrase, not a long quotation)
- Original source title and author/organization
- Publication date
- Direct URL to the primary paper, official report, or authoritative source
- What the source actually studied (sample/population, method, and limits)
- Whether the script wording describes correlation, causation, or an established concept
- Any caveat needed to avoid overstating the evidence

If the episode contains no specific study/statistic/quotation claims, write: "No specific empirical claims; script uses general educational explanation." Do not invent sources or cite search-result snippets. A source must support the exact claim and population in the narration.

Human reviewer: open each URL and confirm it supports the script before public release. This ledger is a research aid, not an independent fact-check.
